# 电路模拟系统

这是一个纯静态的 HTML/CSS/JS 电路模拟工具，不需要安装依赖或启动后端。

## 打开方式

直接用浏览器打开：

```text
D:\10_Leochad\PzMCiphertool-\0elecronic\index.html
```

## 已实现功能

- 夜间控制台界面：暗色网格、发光节点、低噪声侧栏和高对比读数。
- 网格画布编辑：放置、选择、拖动、旋转、复制、删除元件。
- 导线连接：导线工具可连接引脚或网格点，支持连续布线。
- 元件库：电阻、电容、电感、电压源、电流源、地、开关、二极管、LED、灯泡、电压表、电流表、探针。
- 仿真：基于改进节点分析的实时求解，支持直流源、正弦、方波、三角波。
- 瞬态近似：电容使用后向欧拉伴随模型，电感使用支路电流状态。
- 流动演示：根据仿真电流在导线和元件上显示动态发光流向。
- 测量：节点电压标注、元件电压/电流/功率表、示波器波形。
- 示例：LED 限流、RC 方波、分压器、RLC 脉冲。
- 文件：JSON 导入导出、浏览器本地自动保存。

## 操作

- 左侧点击元件后，在画布点击放置。
- 使用顶部导线工具连接两个引脚或网格点。
- 双击开关切换断开/闭合。
- 选中元件后可在右侧属性面板修改参数。
- `R` 旋转选中元件，`W` 切到导线工具，`Delete` 删除选中对象，`Esc` 取消当前工具。

## 模型说明

本工具适合教学、快速验证和低频集总参数电路。二极管/LED 采用分段线性模型，复杂半导体器件、高频传输线、热模型和 SPICE 级精度不在当前实现范围内。
