使用说明 · 模型格式转换台

把各种常见 3D 格式统一转成 GLB，再放进建模实验室的编辑器里使用。

为什么需要这一步

建模实验室的编辑器本体基于 Three.js（WebGPU 渲染，自动回退 WebGL2），它的「本地导入」只接受 .glb / .fbx。其余格式（OBJ、STL、PLY、GLTF 文本、DAE 等）不是渲染引擎的限制， 而是导入入口只做了这两种后缀的校验，所以先用本页转成 GLB 是最省事的通路。

支持导入的格式

  • OBJ（可选 .mtl + 贴图，同目录一起导入可保留材质）
  • STL（二进制 / ASCII 自动识别）
  • PLY（含顶点色点云/网格）
  • GLTF / GLB（含 Draco 压缩、KTX2 贴图、.bin 与外部贴图）
  • FBX（含骨骼动画，动画会随 GLB 导出）
  • DAE / 3DS（兼容性加载，贴图需同目录）

操作步骤

  • 1. 拖入模型文件；带贴图的模型建议直接拖整个文件夹，程序会自动关联贴图与 .bin。
  • 2. 在「模型列表」里切换已导入的模型，右侧预览可左键旋转 / 右键平移 / 滚轮缩放。
  • 3. 需要时打开「自动居中」「底部对齐地面」，方便在编辑器里摆位。
  • 4. 点「导出 GLB 并下载」，得到 <模型名>.glb。
  • 5. 回到建模实验室（ORBITAL HARDWARE STUDIO），用工具栏「本地导入」选择这个 GLB；或直接点本页顶部 「前往建模编辑器」。

注意事项

  • 本页依赖 CDN（unpkg.com）加载 Three.js 与各格式解析器，首次打开需要联网；预览用的环境反射是内置程序化生成的，不需要额外下载。
  • File 格式导出的 GLB 贴图内嵌，不会再有外部依赖；.gltf + 分离贴图转成 GLB 后更不容易丢图。
  • 源文件如果做过 Draco 压缩（体积很小），导出时会解压成完整几何，GLB 会明显变大，属正常现象；导出结果里会给出提示。
  • 顶点数很大的模型（如城市、扫描件）导出会比较慢，注意浏览器内存。
  • 导出不会包含预览用的灯光、网格、环境反射，只有模型本体。
  • 自检：打开 format-convert.html?autotest=1 可跑一遍「导入 → 导出 → 回读」自检，结果输出到页面与控制台。
